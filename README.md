# Домосчёт

Калькуляторы для тех, кто покупает жильё, делает ремонт или проверяет квитанцию.

**Сайт:** https://mecenero1.github.io/domoschet/

![Домосчёт](assets/og.jpg)

## Что умеет

**Ипотека**
- аннуитетный и дифференцированный платёж;
- переплата, срок, доход, при котором платёж не больше 40%;
- досрочное погашение: насколько сократится срок и сколько уйдёт с переплаты;
- график остатка долга и таблица платежей по годам;
- программы: рыночная (18,7%, средняя ставка банков на 11.11.2026), семейная 6%, дальневосточная 2%.

**Материалы для ремонта**
- обои, краска, плитка, ламинат с плинтусом, штукатурка, кладка из газоблока или кирпича, бетон и стяжка;
- размеры комнаты с живым планом, окна и двери вычитаются автоматически;
- запас на подрезку и бой в каждом расчёте;
- смета: собирает материалы в один список и копирует его текстом.

**Коммуналка**
- показания счётчиков воды, электричества (один тариф или день и ночь) и газа;
- водоотведение считается само из расхода воды;
- отопление, содержание дома, капремонт, вывоз мусора, прочие начисления;
- структура квитанции и прогноз при росте тарифов.

## Как устроено

- Один файл `index.html`, без фреймворков и сборщиков. Картинки встроены в страницу, поэтому она открывается целиком одним запросом.
- Пересчёт идёт не чаще одного раза за кадр, большие числа меняются плавно, таблица платежей строится только при открытии.
- Введённые цифры и смета сохраняются в `localStorage` браузера. На сервер ничего не отправляется.
- 3D-картинки отрендерены специально для сайта: сцены описаны в папке `3d/` (GLSL, рейтрейсинг с мягкими тенями и отражениями).

## Структура

```
index.html        готовая страница (её и показывает GitHub Pages)
src/index.html    исходник страницы со ссылками на картинки
build.py          собирает index.html из src/, встраивая картинки
assets/img/       картинки в WebP
assets/og.jpg     превью для ссылок в Telegram и соцсетях
3d/               сцены и скрипт рендера 3D-картинок
```

Правите `src/index.html`, затем запускаете:

```bash
python3 build.py
```
